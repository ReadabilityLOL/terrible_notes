[Wikipedia Link](https://en.wikipedia.org/wiki/Turing_completeness)

Something is Turing complete if it can simulate all other Turing machines i.e. it can do everything another Turing complete tool can do. Technically speaking, a Turing complete software should have infinite memory, but we typically ignore that.

Most programming languages are Turing complete. A way to prove that something is Turing complete is to write another Turing complete thing in it, e.g. [[brainf|Brainf***]].

- [[Conway's Game of Life]]
